---
title: Quickstart
description: Run the Rust server with an exported StyleTTS2 model.
---

Enter the development environment and run the CPU backend:

```bash
nix develop
cargo run --manifest-path tinfer_rust/Cargo.toml --features onnx -- tinfer_rust/config.yaml
```

Set the model path in the YAML file to an exported model directory, its backend to `onnx`,
and its device to `cpu`. Configure its model ID and explicit synthesis settings.
An export contains `model.toml`, `voices/*.tinf`, and `onnx/cpu/{A,BC}.{onnx,tinf}`.

```bash
curl -H 'Content-Type: application/json' \
  -d '{"text":"Dzień dobry.","model_id":"magda"}' \
  'http://localhost:8000/v1/text-to-speech/magda_001?output_format=pcm_24000' \
  -o speech.pcm
```

The response is signed 16-bit little-endian mono PCM at 24 kHz.
Model-conversion commands are documented in the repository README.

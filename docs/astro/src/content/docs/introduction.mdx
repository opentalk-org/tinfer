---
title: Tinfer Rust
description: Streaming speech synthesis in Rust.
---

Tinfer serves StyleTTS2 through a Rust engine and native ONNX Runtime or TensorRT execution.

The engine cuts buffered text into synthesis units and schedules model calls across streams.
Each unit starts with a feature-generation call, followed by audio-generation calls.

Use [Quickstart](/quickstart) to run the server. Python model definitions are retained only
for export tooling; synthesis and server lifecycle run in Rust.

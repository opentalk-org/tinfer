---
title: Alignments
description: Alignment metadata accompanying audio chunks.
---

`AlignmentType` supports `Word`, `Char`, `Phoneme`, and `None`. Configure it through
`StreamParams.alignment_type` or the server defaults.

StyleTTS2 derives timings from predicted phoneme durations. Character timings are
interpolated within mapped words. Each emitted audio window clips its alignment
and rebases time to the beginning of that window.

`AudioChunk.text_span` identifies the source text unit in Unicode character positions.
Several audio chunks can refer to the same text unit. Raw model alignment positions
are local to that unit; consumers must account for the source span when displaying text.
See [Alignment](/api/alignment) and the transport-specific timestamp responses.

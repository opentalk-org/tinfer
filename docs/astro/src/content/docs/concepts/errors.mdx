---
title: Error handling
description: Rust results and transport errors.
---

Engine operations return `Result<T, Error>`. The error variants are `Validation`,
`Catalog`, `Inference`, `Cancelled`, and `Shutdown`.

Audio delivery returns errors separately from successful `AudioChunk` values;
there is no error field on an audio chunk. Cancellation invalidates in-flight deliveries.
HTTP and WebSocket map engine failures into their protocol error responses; gRPC
returns status errors.

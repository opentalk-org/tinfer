---
title: Parameters
description: Configuration and request settings in Rust.
---

Server defaults live in the YAML `defaults` section. `chunk_length_schedule` controls
text lengths, `inactivity_timeout_ms` controls the text deadline, and `alignment_type`
selects alignment output.

Model settings live in each configured model's `settings` object. Rust callers can
override them through `StreamParams.model`; the engine merges overrides at stream creation.
All required StyleTTS2 settings must be explicit.

`engine.engine_timeout_ms` is the batch-collection wait, separate from the text deadline.
See [Config](/api/streaming-tts-config) and [StyleTTS2 parameters](/api/styletts2-params).

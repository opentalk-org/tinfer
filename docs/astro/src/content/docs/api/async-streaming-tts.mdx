---
title: AsyncEngine
description: The asynchronous Rust engine interface.
---

`AsyncEngine::new(Engine)` wraps the synchronous engine. Its async operations use
blocking tasks to avoid blocking the Tokio runtime.

It exposes model and voice discovery, model loading and unloading, `create_stream`,
`start_stream`, `generate_full`, and `stop`. `AsyncStream` provides asynchronous stream
operations and audio delivery. The source is `tinfer_rust/src/engine/async_engine.rs`.

---
title: Alignment
description: The Rust alignment structures.
---

`Alignment` contains a kind and a list of `AlignmentItem` values.
Each item has text, character boundaries, and start/end milliseconds.

`AlignmentType` selects word, character, phoneme, or no alignment. Audio-window timings
are local to each chunk. See [Alignments](/concepts/alignments) for source-position handling.

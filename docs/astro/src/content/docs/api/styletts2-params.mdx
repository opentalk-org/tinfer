---
title: StyleTTS2 parameters
description: Explicit settings for the Rust StyleTTS2 model.
---

Configure these fields in model `settings`; Rust callers can override them through
`StreamParams.model`. Missing required fields and unknown fields are rejected.

| Field | Purpose |
| --- | --- |
| `use_diffusion` | Enable diffusion refinement |
| `phonemized` | Treat input as phonemes |
| `language` | Language code; empty uses the model language |
| `embedding_scale` | Diffusion guidance scale |
| `diffusion_steps` | Between 2 and 5 |
| `style_interpolation_factor` | Style continuity between text units |
| `alpha`, `beta` | Reference/predicted style mixing |
| `speed` | Positive speaking-rate multiplier |
| `seed` | Fixed seed or explicit null |
| `apply_text_normalization` | `auto`, `on`, or `off` |

See `tinfer_rust/config.yaml` for a complete settings object.

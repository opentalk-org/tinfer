---
title: Stream
description: A Rust streaming synthesis request.
---

A stream belongs to one model and voice. Its operations are:

| Operation | Purpose |
| --- | --- |
| `add_text` | Append text |
| `force_generate` | Make buffered text ready |
| `try_generate` | Wake the scheduler |
| `finish` | Force remaining text and mark input finished |
| `recv` | Wait for audio, an end marker, or an error |
| `get_audio` | Drain available deliveries |
| `collect_audio` | Collect through the next end marker |
| `get_state` | Read model state |
| `cancel` | Cancel generation |
| `close` | Release the stream |

After current input is drained, the stream can accept more input until it is closed.

---
title: Config
description: Rust server configuration.
---

The YAML maps to Rust `Config` and includes `engine`, `defaults`, `grpc`, `web`, and `models`.

`engine` defines queue capacity and batch wait. `defaults` defines text chunk schedules,
text timeout, and alignment. Server sections define addresses and transport settings.
Each model supplies ID, model type, export path, backend, device, maximum batch size,
and explicit model settings.

Backend choices are `onnx` and `tensorrt`; devices are `cpu`, `cuda:N`, and `auto`.
TensorRT requires CUDA. Build features are `onnx`, `onnx-cuda`, and `tensorrt`.
Use `tinfer_rust/config.yaml` as the configuration example.

---
title: AudioChunk
description: The Rust audio delivery structure.
---

`AudioChunk` contains `audio: Vec<f32>`, `sample_rate: u32`, `chunk_index: u64`,
`text_span: Range<usize>`, and optional `alignment`.

The index advances for each nonempty audio output. The span refers to its text unit;
multiple audio windows can share that span. Errors arrive through `Result`, separately.

`AudioChunk::merge` concatenates audio and checks sample rates. It returns the overall
text span and does not merge alignment metadata.

---
title: Engine
description: The synchronous Rust inference engine.
---

`Engine::new(Config)` validates configuration, loads models, starts caller workers,
and launches the scheduling coordinator.

Use `create_stream` for incremental input or `start_stream` for immediate input.
`generate_full` collects and merges audio. Model discovery, voice discovery, loading,
and unloading are available on the engine. `stream_params` returns configured defaults.

Call `stop` to close active streams and join workers. The Rust source is
`tinfer_rust/src/engine/engine.rs`.

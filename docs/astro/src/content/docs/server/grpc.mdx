---
title: gRPC
description: The StyleTTSService contract served by Tinfer Rust.
---

The service contract is `tinfer_rust/proto/styletts.proto`, package `styletts.v1`.
Generate client bindings from this file using your language's Protobuf tooling.

| RPC | Behavior |
| --- | --- |
| `Health` | Serving status |
| `ListModels` | Model IDs and languages |
| `ListVoices` | Voices for a model |
| `Synthesize` | Full audio response |
| `SynthesizeStream` | Stream audio for complete input text |
| `SynthesizeIncremental` | Bidirectional text input and audio output |

Synthesis requests provide text and a `SynthesisConfig` with model, voice, language,
and sample rate. Incremental input begins with configuration,
then sends text, force-synthesis, or cancellation messages.

Enable gRPC and set its address in the server YAML. Start the Rust binary with that
configuration; there is no separate Python server or bundled Python client package.

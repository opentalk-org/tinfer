---
title: Server overview
description: Rust gRPC, HTTP, and WebSocket serving.
---

The binary loads a YAML `Config`, creates an `Engine` and `AsyncEngine`, and starts the
configured gRPC and web servers. Both use the same scheduler and loaded models.

```bash
cargo run --manifest-path tinfer_rust/Cargo.toml --features onnx -- tinfer_rust/config.yaml
```

The `grpc` section controls its enabled flag and address. The `web` section controls
HTTP, WebSocket access, output format, alignment, and connection inactivity.
The process handles Ctrl-C by stopping its servers and engine.

Read [gRPC](/server/grpc), [HTTP](/server/http), or [WebSocket](/server/websocket)
for transport contracts. `/health`, `/health/ready`, and `/health/live` expose serving status.
